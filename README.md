# 国道走破アプリ

走った国道を赤で塗る地図の、**スマホで完結する版**です。
記録は端末の中に保存され、電波が無くても地図も記録も使えます。
PC 版（国道管理v2）とは CSV を書き出し・読み込みしてやり取りします。

## 使いかた

1. 公開 URL をスマホで開く（初回はネットが要ります。20MB ほど読み込みます）
2. ホーム画面に追加する（Android: Chrome のメニュー →「ホーム画面に追加」、
   iPhone: Safari の共有 →「ホーム画面に追加」）
3. 「≡」→「全路線を端末に保存」を一度押しておくと、どの路線も圏外で記録できます

**記録する**: 交差点名か道の線を押して「ここから」、もう一方を押して「ここまで」。
その場で赤くなります。道の駅は星を押して「行った」です。

**PC と共有する**: 「≡」→「routes.csv を書き出す」で共有メニューが開くので、
PC に送って PC 版の `記録/` に置きます。逆に PC 版の routes.csv を「CSV を読み込む」で
取り込めます（いまの記録は置き換わります）。

背景の地図（国土地理院）はネットがあるときだけ出ます。圏外では代わりに海岸線と県境を薄く描きます。
ネットのあるときに見た範囲は、ブラウザの一時保存でしばらく圏外でも見えることがありますが、
見ていない場所は白いままです。

## 開発

ビルド工程はありません。ファイルをそのまま配れば動きます。

```
python tools/export_data.py     PC 版（https://github.com/sabanekko3/KokudoRecord）の導出データから data/ を作る
python tools/compare.py         同じ routes.csv を PC 版と JS で解いて突き合わせる
python tools/smoke.py           ヘッドレス Edge で起動と記録の操作を通す
python -m http.server 8000      手元で開く（http://localhost:8000/）
```

手元で開くときは `file://` ではなく http.server を使ってください
（サービスワーカーと fetch が `file://` では動きません）。
URL に `?debug` を付けると進み具合が画面の下に出ます。

画面や道路データを更新したら `js/version.js` の `APP_VERSION` を上げてから push してください。
上げないと端末に古いものが残ります。届いた版は題名の「v0.2」で分かります。

設計と注意点は [CLAUDE.md](CLAUDE.md)、画面と操作の仕様は [docs/仕様.md](docs/仕様.md) にあります。
