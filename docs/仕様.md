# 国道走破アプリ 仕様

## 1. 目的と範囲

- 走った国道の区間を記録し、走破済みを赤、未走破を青で地図に描く
- 計算・記録・表示はすべて端末の中で完結し、**通信なしで使える**
- PC 版（国道管理v2）と記録を CSV でやり取りできる
- 対象外: 都道府県・市町村での区間指定、Overpass からの取得（データは PC 版で作って配る）

## 2. 画面

上下2段（横幅 760px 以下）。上が地図、下がパネル。横幅が広いときは左右。

### パネル

| 部分 | 内容 |
|---|---|
| 見出し | 名前と「≡」ボタン。≡ で設定と記録の持ち出しを開閉（開くとパネルが 75% に伸びる） |
| 走破率 | 帯・距離の割合・内訳（走破 km／総延長、全線走破と一部走破の本数、道の駅） |
| 編集の帯 | 区間の記録中の案内、結果、エラー。「閉じる」で消える |
| 設定 | 背景（背景なし／白地図／淡色／標準／空中写真。「なし」以外は要ネット）、濃さ、未走破を描く、交差点名を出す、道の駅を出す |
| 記録の持ち出し | routes.csv を書き出す／michinoeki.csv を書き出す／CSV を読み込む |
| データ | 道路データの版と路線数、「全路線を端末に保存」 |
| タブ | 路線（一覧と絞り込み）／走破記録（記録の一覧・編集・削除） |

### 地図

- 未走破の線（青、細い）と走破済みの線（赤、太い）。一覧で路線を選ぶと、その路線だけ濃く出て橙の縁取りが付く
- 拡大すると地点の印（●信号交差点、◆国道どうしの交点、◆路線の端）、さらに拡大すると名前と `R番号/km`
- 道の駅は星（訪問済みは赤、未訪問は青）。設定で出し入れ

## 3. 操作

### 区間を記録する

1. 地点の名前、または道の線を押す
2. ポップアップの「ここから」を押す（重複区間では路線ごとにボタンが出る）
3. もう一方の地点や線を押し、「ここまで」を押す
4. 経路を計算し、その場で赤くなる。走破日は当日

区間の書き方（routes.csv に入る文字列）:

| 押したもの | 区間欄に入る形 |
|---|---|
| 名前のある地点（km あり） | `名前@km` |
| 名前のある地点（距離不明） | `名前@緯度/経度` |
| 道の線の任意の場所 | `@緯度/経度`（小数5桁） |

2点は `〜` で繋ぐ。同名の地点が複数あるときは、km か座標で最も近いものを採る。
2点を繋ぐ経路が無いときは記録せず、理由を帯に出す。

### 道の駅

星を押して「行った」で訪問日（当日）が入る。「訪問を取り消す」で消える。

### 走破記録タブ

- 行を押すと、その記録の区間だけを縁取りして地図をそこへ寄せる。もう一度押すと解除
- 「編集」で走破日とメモを直せる。「削除」は確認のあと消し、その路線を計算し直す
- 解釈できない行（都道府県指定など）は赤い注意書きが付く。地図には反映されない

### 記録の持ち出し

- 書き出し: 端末の「共有」（Android / iOS）で送る。共有が使えない環境ではダウンロード
- 読み込み: routes.csv か michinoeki.csv を選ぶ。見出し行で判別する。**既存の記録は置き換わる**
  （確認あり）。michinoeki.csv は訪問日かメモのある行だけ取り込む

## 4. CSV の形式（PC 版と同一）

routes.csv: `路線番号,区間,走破日,メモ`。BOM 付き UTF-8、改行 LF。
路線番号は数字だけで書く（読み込み時に `R17`・`国道17号` も受ける）。

michinoeki.csv: `都道府県,道の駅,訪問日,メモ`。全駅を並べ、訪問した駅に日付が入る。
一覧に無い駅の記録も末尾に残す。駅名は「道の駅」の接頭辞と全角空白を落とした形。

## 5. 計算

- 路線の道路網は、座標が一致する点で繋がったグラフ。辺の重みはハバーサインの km
- `全線` は全辺。`A〜B` は Dijkstra の最短経路が通る辺
- 路線の走破距離は走破した辺の km の和。全国の走破距離は**路線をまたいだ辺の集合の和**
  （重複区間を二重に数えない）
- 状態: 走破した辺が無ければ「未走破」、走破 km が延長の 98% 以上なら「全線走破」、それ以外は「一部走破」
- 線の切り分けは導出時の間引きの印（keep）を使い、走破／未走破の境目でも形が揺れない
- 計算結果は PC 版と辺の集合まで一致する（`tools/compare.py`）

## 6. データと更新

- `data/` は PC 版の `cache/derived/` から `tools/export_data.py` で作る（形式は CLAUDE.md）
- 道路データを更新する手順: PC 版で `fetch` → アプリ側で `export_data.py` → `sw.js` の
  `CACHE` を上げる → commit → push。端末側は次にオンラインで開いたときに入れ替わる
- 記録の保存先は IndexedDB（`kokudo` データベース、`records` と `eki`）。
  端末のブラウザデータを消すと記録も消えるので、CSV の書き出しを控えにする

## 7. オフライン

- 最初に開いたときに画面・Leaflet・全国の線・地点・道の駅を端末に保存する
- 路線ごとの形状は、記録したときに保存する。「全路線を端末に保存」で先に全部入れられる（25MB）
- 背景地図（国土地理院のタイル）は保存しない。オフラインでは「背景なし」にする

## 8. 配布

静的ファイルなので、GitHub Pages などに置けば URL を開くだけで使える。
ホーム画面に追加するとアプリとして開く（Android は Chrome のメニュー、iPhone は Safari の共有）。
